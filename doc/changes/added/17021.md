- Support the suffixed stub libraries of Relocatable OCaml (OCaml 5.5): when
  the compiler reports a `bytecode_runtime_id`, stub DLLs are named
  `dll<name>-<target>-<bytecode_runtime_id>` and recorded in libraries with
  `-dllib-suffixed`. This is controlled by the new
  `(suffixed_stub_libraries <bool>)` field of `dune-project`, which defaults to
  `true` from `(lang dune 3.26)`. The new `%{stub_dll_suffix}` variable expands
  to the suffix in use, if any (#17021, @dra27)
