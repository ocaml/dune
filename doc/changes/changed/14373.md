- BREAKING CHANGE: Actions no longer see the shared install staging area
  (`_build/install/<context>/{bin,lib,lib/stublibs}`) on `PATH`, `OCAMLPATH` and
  `CAML_LD_LIBRARY_PATH`. An action's environment only contains the packages it
  declares with `(deps (package <pkg>))` (and their library closure, see below).
  Actions that rely on packages being visible (such as tests that `#require` the
  package under test from an mdx block, steps that run `ocamlfind`, a nested `dune`
  build, or load a bytecode stub library) must now declare the package
  dependency explicitly.
  (#14373, #16617, @Alizter)

- `(package <pkg>)` now also includes the packages owning the library closures
  of libraries in workspace and installed packages. Installed packages reached
  through those closures also work with Dune language versions older than 2.9.
  (#14373, #16362, #16529, @Alizter, @anmonteiro)
