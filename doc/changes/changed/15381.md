- In a package with a `(dir ...)` field, `%{bin:...}`, `%{bin-available:...}`
  and the `PATH` seen by actions now only find binaries installed by the
  packages in the transitive closure of that package's `(depends ...)` field.
  Previously every package in the lock directory was searched, and every
  workspace package's binary was visible. Stanzas that relied on an undeclared
  package's binary must now declare it. Binaries found on the ambient `PATH`,
  and those bound by `(env (binaries ...))`, are unaffected. (#15381,
  @punchagan)
