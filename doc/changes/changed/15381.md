- When dune package management is enabled, `%{bin:...}`, `%{bin-available:...}`
  and the `PATH` seen by actions, for a package with a `(dir ...)` field, now
  only find binaries installed by the packages listed in that package's
  `(depends ...)` and `(depopts ...)` fields. Dependencies of those packages are
  not included unless they are listed too. This applies to both lock directory
  and sibling workspace packages, and fewer lock directory packages are now
  built as a result. Stanzas that relied on an undeclared package's binary must
  now declare it. Binaries on the ambient `PATH` and those bound by
  `(env (binaries ...))` are unaffected, as are directories with no owning
  package. Library resolution is unchanged. (#15381, @punchagan)
