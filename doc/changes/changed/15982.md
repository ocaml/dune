- Portable lock directories now solve all requested platforms together. A
  package selected on multiple platforms uses the same version on each, while
  packages and dependency alternatives can remain platform-specific. Dune
  selects a common version when one exists and reports a conflict when it does
  not. Repeated `solve_for_platforms` entries are ignored. Diagnostics label
  platform-specific dependency failures and cross-platform version rejections
  with the relevant platform. The cross-platform version constraint was
  proposed by @art-w. (#15982, fixes #13647, @Alizter)
