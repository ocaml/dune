- BREAKING CHANGE: Rules declaring file targets may no longer produce
  directories, even with older Dune language versions. Use `(dir ...)` targets
  instead: these require language version 3.0 or newer, and
  `(using directory-targets 0.1)` before 3.24. Entirely empty directory outputs
  must be restructured, for example by adding a marker file. (#16564, @Alizter)
