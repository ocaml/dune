- Actions no longer find the executables of all locked packages in the `PATH`.
  Instead, they must depend on them through `%{bin:...}` or `(deps (package
  ...))`, so that they are rerun when those binaries change.  As an exception,
  the toolchain executables such as `ocamlc` remain available. Directories of
  the build directory present in the `PATH` dune is run with, such as those
  added by `eval $(dune tools env)`, are removed as well. (#17023, #1706, fixes
  #17004, @mefyl)
