- Make `(deps (package ...))` include the workspace libraries in the transitive
  closure of the OCaml libraries it installs, including deprecated-name
  redirect targets, PPX runtime dependencies, and virtual-library default
  implementations. This lets OCaml tools resolve the same library closure
  before and after installation without exposing the libraries' complete
  owning packages or following the broader, and not always available, package
  dependency graph. (#15511, @Alizter)
