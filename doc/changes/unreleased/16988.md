- Add `(odoc <true|false|auto>)` to the `package` stanza. When the package's
  documentation is disabled, the generated opam file no longer depends on
  `odoc` nor builds `@doc`, and the `@doc` aliases skip the package. With
  `(odoc auto)`, the default from lang 3.26 with the unreleased extension,
  documentation is only built for packages with a library or a
  `documentation` stanza. Packages defined by an opam file rather than in
  `dune-project` keep `(odoc true)` (#16988, fixes #5519, @cuihtlauac)
