cinaps
------

A ``cinaps`` stanza is available to support the ``cinaps`` tool.  See the
`cinaps website <https://github.com/janestreet/cinaps>`_ for more details.

With :ref:`format-generated-corrections` set to ``true`` in ``dune-project``
(available since Dune 3.26), Cinaps corrections are formatted according to the
source's formatting configuration before comparison or promotion. This does not
require a particular Cinaps extension version.
