cinaps
------

A ``cinaps`` stanza is available to support the ``cinaps`` tool.  See the
`cinaps website <https://github.com/janestreet/cinaps>`_ for more details.

With ``(using cinaps 1.4)`` (available since Dune 3.26), generated OCaml
corrections are formatted with OCamlFormat according to the source's formatting
configuration before being compared or promoted. Earlier extension versions
retain unformatted corrections.
